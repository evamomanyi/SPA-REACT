# Project Portfolio

## Overview

The Project Portfolio Landing Page is a Single Page Application (SPA) built using React and Vite. The application allows users to manage a portfolio of projects by adding new projects, viewing project details, and searching through existing projects.

## Features

- Add new projects dynamically
- Search projects by title
- Responsive design for mobile, tablet, and desktop
- Component-based architecture
- Custom React Hooks
- Jest and React Testing Library support

## Technologies Used

- React
- Vite
- JavaScript (ES6+)
- CSS3
- Jest
- React Testing Library

## Installation

```bash
npm install
npm run dev
```

Open:

http://localhost:5173

## Functionality

### Add Project

Users can enter:

- Project Title
- Project Description

and click **Add Project** to add the project to the list.

### Search Projects

Users can search projects by title using the search bar. Results are filtered in real time.
